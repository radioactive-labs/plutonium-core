# RBAC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an experimental, permission-based role system (`Plutonium::Rbac`) whose permissions are derived from resources and plug into Plutonium policies by default.

**Architecture:** Permissions are computed from resource definitions and policies (`Catalog`). Roles are DB rows holding permission-key arrays; any model can hold roles through a polymorphic `RoleAssignment`. A policy mixin makes the core predicates and custom-action rules default to "does the current holder have this key", with a per-request cache in `Rbac::Current`. Everything is gated by `config.rbac.enabled`, which also gates the gem-shipped migration.

**Tech Stack:** Ruby/Rails, ActionPolicy, Phlex/Phlexi forms, Stimulus, Minitest + Appraisal, Rails generators.

**Spec:** `docs/superpowers/specs/2026-11-07-rbac-design.md`

**User Verification:** NO — no user verification required beyond normal review.

## Deviations from the spec (decided while planning)

1. **No `rbac_resource_key` override.** The resource segment of a key is always `model_name.i18n_key`, so a portal policy and its base policy can never disagree about a key.
2. **The Role model's key prefix is `rbac_role`**, not `plutonium/rbac/role`, because the model pins `model_name` to `RbacRole` (same reason AsyncRun does: clean routes and helpers).
3. **The "is this a system role" column is `system_role`**, not `system`, to avoid shadowing `Kernel#system`.
4. **Holder tenant** comes from `Holder#rbac_entity` (default `nil`), which the installer generates for holders given with an association (`OrganizationUser:organization`).
5. **`--holders` takes `Class[:entity_association]` entries**, and there is a `--policy` option (default `ResourcePolicy`) naming the policy class to receive the mixin.

```ruby
# lib/plutonium/rbac/matcher.rb
# frozen_string_literal: true

module Plutonium
  module Rbac
    # Wildcard-aware matching of a key against a set of granted keys.
    #
    # Granted keys may be exact ("blogging/post.read"), a resource wildcard
    # ("blogging/post.*") or global ("*"). The key being checked may itself be
    # a wildcard (the escalation guard checks a role's keys against the actor's),
    # in which case only an equal or broader wildcard grants it.
    module Matcher
      module_function

      def grants?(granted, key)
        return true if granted.include?("*") || granted.include?(key)
        return false if key == "*"

        resource_wildcard = "#{key.split(".").first}.*"
        return false if key == resource_wildcard

        granted.include?(resource_wildcard)
      end
    end
  end
end
```

```ruby
      def permission(key, label: nil, group: nil)

          label: label || key.tr(".", " ").humanize,
```

```ruby
# lib/plutonium/rbac/catalog.rb
# frozen_string_literal: true

module Plutonium
  module Rbac
    # Every grantable permission key, derived from code.
    #
    # Sources: each resource with a definition gets the standard permissions;
    # every action declared on any of its definitions (base or portal) that is
    # not one of Plutonium's built-in actions becomes a permission; restricted
    # attributes declared on its RBAC policies add <field>.read/<field>.write;
    # plus anything declared through Plutonium::Rbac.permission.
    #
    # Built lazily (it needs the app eager loaded) and reset on reload.
    class Catalog
      STANDARD_ACTIONS = %i[read create update destroy export].freeze

      class << self
        def instance = @instance ||= new.tap(&:build)

        def reset! = @instance = nil

        delegate :permissions, :keys, :key?, :grouped, :custom_actions_for, to: :instance
      end

      attr_reader :permissions, :keys

      def build
        Plutonium.eager_load_rails!

        @custom_actions = Hash.new { |h, k| h[k] = Set.new }
        @restricted_fields = Hash.new { |h, k| h[k] = Set.new }

        definitions.each do |definition|
          @custom_actions[definition.model_class_or_nil].merge(definition.defined_actions.keys - builtin_action_names)
        end

        rbac_policies.each do |policy|
          model = Rbac::Policy.resource_class_for(policy)
          @restricted_fields[model].merge(policy.rbac_restricted_attribute_names) if model
        end

        @permissions = resource_permissions + Rbac.declared_permissions.values
        @keys = @permissions.to_set(&:key)
      end

      def key?(key) = keys.include?(key)

      def grouped = permissions.group_by(&:group)

      def custom_actions_for(resource_class) = @custom_actions.fetch(resource_class) { Set.new }

      private

      def definitions
        Plutonium::Resource::Definition.descendants.select { |klass| klass.name && klass.model_class_or_nil }
      end

      def rbac_policies
        Plutonium::Resource::Policy.descendants.select { |klass| klass.name && klass < Rbac::Policy }
      end

      def builtin_action_names = Plutonium::Resource::Definition.defined_actions.keys

      def resource_permissions
        models = (@custom_actions.keys + @restricted_fields.keys).uniq.sort_by(&:name)
        models.flat_map do |model|
          prefix = model.model_name.i18n_key.to_s
          group = model.model_name.human(count: 2)
          actions = STANDARD_ACTIONS + custom_actions_for(model).to_a.sort
          fields = @restricted_fields.fetch(model) { Set.new }.to_a.sort

          actions.map { |action|
            Permission.new(key: "#{prefix}.#{action}", resource: model, action:, label: action.to_s.humanize, group:)
          } + fields.flat_map { |field|
            %i[read write].map do |mode|
              Permission.new(key: "#{prefix}.#{field}.#{mode}", resource: model, action: :"#{field}.#{mode}",
                label: "#{model.human_attribute_name(field)} (#{mode})", group:)
            end
          }
        end
      end
    end
  end
end
```

```ruby
module Plutonium
  module Rbac
    # Per-request (and per-job) RBAC state. Rails resets CurrentAttributes
    # between requests and jobs.
    #
    # - permission_cache: holder -> Set of keys, so a 50-row table runs one query.
    # - actor_resolver: set by controllers; a lambda returning the acting
    #   holder. Its presence turns on the escalation guard. Absent in console,
    #   seeds and sync, where there is no acting user.
    # - permission_override: testing hook (Plutonium::Testing::Rbac).
    class Current < ActiveSupport::CurrentAttributes
      attribute :permission_cache, :actor_resolver, :permission_override

      def permission_keys_for(holder)
        return permission_override if permission_override
        return Set.new if holder.nil?

        self.permission_cache ||= {}
        permission_cache[[holder.class.polymorphic_name, holder.id]] ||= holder.rbac_permission_keys_uncached
      end

      def enforcing? = !actor_resolver.nil?

      def actor = actor_resolver.call

      def invalidate! = self.permission_cache = nil
    end
  end
```

```ruby
# lib/plutonium/rbac/holder.rb
# frozen_string_literal: true

module Plutonium
  module Rbac
    # Include in any model that holds roles (a membership, a user, an admin,
    # a pending invite).
    #
    # `rbac_role_ids=` stages the change rather than writing through the
    # has_many: Rails' generated ids writer saves immediately on a persisted
    # record, outside the holder's save, so a rejected assignment would raise
    # mid-assign_attributes. Staged ids validate with the holder and sync after it saves.
    module Holder
      extend ActiveSupport::Concern

      included do
        has_many :rbac_role_assignments, class_name: "Plutonium::Rbac::RoleAssignment", as: :holder, dependent: :destroy
        has_many :rbac_roles, through: :rbac_role_assignments, source: :role

        validate :validate_staged_rbac_roles
        after_save :sync_staged_rbac_roles
      end

      # The tenant this holder belongs to; tenant roles must match it.
      # Override (the installer generates one for membership holders).
      def rbac_entity = nil

      def rbac_permission_keys = Current.permission_keys_for(self)

      def rbac_permission_keys_uncached
        return Set.new if new_record?

        rbac_roles.pluck(:permissions).flatten.to_set
      end

      def rbac_granted?(key) = Matcher.grants?(rbac_permission_keys, key.to_s)

      def rbac_role_ids = @staged_rbac_role_ids || rbac_role_assignments.pluck(:role_id)

      def rbac_role_ids=(ids)
        @staged_rbac_role_ids = Array(ids).compact_blank.map { |id| Integer(id) }.uniq
      end

      private

      def validate_staged_rbac_roles
        return if @staged_rbac_role_ids.nil?

        roles = Role.where(id: @staged_rbac_role_ids).to_a
        errors.add(:rbac_roles, :invalid) if roles.size != @staged_rbac_role_ids.size

        existing = new_record? ? [] : rbac_role_assignments.pluck(:role_id)
        roles.reject { |role| existing.include?(role.id) }.each do |role|
          assignment = RoleAssignment.new(holder: self, role:)
          next if assignment.valid?

          assignment.errors.each { |error| errors.add(:rbac_roles, error.message) }
        end
      end

      def sync_staged_rbac_roles
        ids = @staged_rbac_role_ids
        return if ids.nil?

        @staged_rbac_role_ids = nil
        existing = rbac_role_assignments.pluck(:role_id)
        rbac_role_assignments.where(role_id: existing - ids).destroy_all
        (ids - existing).each { |role_id| rbac_role_assignments.create!(role_id:) }
        Current.invalidate!
      end
    end
  end
end
```

```ruby
# lib/plutonium/rbac/policy.rb
# frozen_string_literal: true

module Plutonium
  module Rbac
    # Policy mixin: core predicates and custom-action rules default to the
    # current holder's permissions.
    #
    #   class ResourcePolicy < Plutonium::Resource::Policy
    #     include Plutonium::Rbac::Policy
    #   end
    #
    # Combine a grant with record state by overriding and calling super:
    #
    #   def publish? = super && record.draft?
    module Policy
      extend ActiveSupport::Concern

      included do
        class_attribute :rbac_restricted_attribute_names, instance_accessor: false, default: [].freeze
      end

      class_methods do
        # Fields hidden unless <resource>.<field>.read / .write is granted.
        def rbac_restricted_attributes(*names)
          self.rbac_restricted_attribute_names = (rbac_restricted_attribute_names + names.map(&:to_sym)).uniq.freeze
        end
      end

      # The model a policy class governs, inferred from its name the same way
      # Definition::Base infers a model: strip "Policy", then search outward
      # through the namespaces (OrgPortal::Blogging::PostPolicy -> Blogging::Post).
      def self.resource_class_for(policy_class)
        segments = policy_class.name.split("::")
        base = segments.pop.delete_suffix("Policy")
        segments.size.downto(0) do |i|
          klass = (segments.last(i) + [base]).join("::").safe_constantize
          return klass if klass.is_a?(Class) && klass < ActiveRecord::Base
        end
        nil
      end

      def read? = granted?(:read)

      def create? = granted?(:create)

      def update? = granted?(:update)

      def destroy? = granted?(:destroy)

      def export_csv? = granted?(:export)

      # A symbol expands to "<resource>.<action>"; a string is a full key.
      def granted?(action_or_key)
        key = action_or_key.is_a?(Symbol) ? "#{rbac_resource_key}.#{action_or_key}" : action_or_key.to_s
        Matcher.grants?(rbac_permission_keys, key)
      end

      def rbac_holder
        return @rbac_holder if defined?(@rbac_holder)

        @rbac_holder = Rbac.holder_for(user:, entity_scope:)
      end

      def rbac_permission_keys = Current.permission_keys_for(rbac_holder)

      def rbac_resource_key = resource_class.model_name.i18n_key.to_s

      def respond_to_missing?(name, include_private = false)
        rbac_custom_action(name) ? true : super
      end

      def method_missing(name, *args, &)
        action = rbac_custom_action(name)
        action ? granted?(action) : super
      end

      private

      def rbac_custom_action(name)
        name = name.to_s
        return unless name.end_with?("?")

        action = name.delete_suffix("?").to_sym
        action if Catalog.custom_actions_for(resource_class).include?(action)
      end
    end
  end
end
```

```ruby
  module Rbac
    module Policy
      # Prepended onto every RBAC policy class AND each subclass (via
      # inherited), so a subclass's own permitted_attributes_for_* override is

      module AttributeFilter
        READ_SIDE = %i[read index show export].freeze
        WRITE_SIDE = %i[create update new edit].freeze
```

```ruby
# lib/plutonium/rbac/role_policy.rb
# frozen_string_literal: true

module Plutonium
  module Rbac
    # Managing roles is itself RBAC-gated (rbac_role.read, .create, ...), so a
    # system Owner role with "*" covers it and nothing special-cases admins.
    class RolePolicy < Plutonium::Resource::Policy
      include Plutonium::Rbac::Policy

      # Default scoping would hide global roles (they have no entity), so it is
      # skipped on purpose and the tenant filter is written out here.
      relation_scope do |relation|
        skip_default_relation_scope!
        global = relation.where(entity_type: nil, entity_id: nil)
        entity_scope ? global.or(relation.where(entity: entity_scope)) : global
      end

      def update? = super && editable_here?

      def destroy? = super && editable_here?

      def permitted_attributes_for_create = %i[name key description permissions]

      def permitted_attributes_for_read = %i[name key description permissions system_role created_at]

      private

      # System roles belong to code; a tenant cannot edit global roles.
      def editable_here? = !record.system_role? && record.entity == entity_scope
    end
  end
end
```

```js
// Select-all helpers for the RBAC permission grid
// (Plutonium::UI::Form::Components::RbacPermissions).
export default class extends Controller {

  connect() {
    this.sync()
  }

  toggleGroup(event) {
    const group = event.target.closest("[data-rbac-permissions-target='group']")
    group.querySelectorAll("[data-rbac-permissions-target='permission']").forEach((box) => {
      box.checked = event.target.checked
    })
    this.sync()
  }

  toggleAction({ params: { action } }) {
    const boxes = this.permissionTargets.filter((box) => box.dataset.actionName === action)
    const check = !boxes.every((box) => box.checked)
    boxes.forEach((box) => { box.checked = check })
    this.sync()
  }

  sync() {
    this.groupTargets.forEach((group) => {
      const boxes = [...group.querySelectorAll("[data-rbac-permissions-target='permission']")]
      const toggle = group.querySelector("[data-rbac-permissions-target='groupToggle']")
      const checked = boxes.filter((box) => box.checked).length
      toggle.checked = checked === boxes.length
      toggle.indeterminate = checked > 0 && checked < boxes.length
    })
  }
}
```

```ruby
# lib/generators/pu/rbac/install_generator.rb
# frozen_string_literal: true

require_relative "../lib/plutonium_generators"

module Pu
  module Rbac
    class InstallGenerator < Rails::Generators::Base
      include PlutoniumGenerators::Generator
      include PlutoniumGenerators::Concerns::ResourceRegistration

      source_root File.expand_path("templates", __dir__)

      desc(
        "Enable experimental RBAC, wire role holders and the policy mixin, and connect roles to a portal\n\n" \
        "e.g. rails g pu:rbac:install --holders=OrganizationUser:organization Admin --dest=org_portal"
      )

      class_option :holders, type: :array, required: true,
        desc: "Holder models, optionally with their tenant association (OrganizationUser:organization)"
      class_option :policy, type: :string, default: "ResourcePolicy",
        desc: "Policy class that receives Plutonium::Rbac::Policy"
      class_option :user_association, type: :string, default: "user",
        desc: "Association from a membership holder to the user"
      class_option :skip_portal, type: :boolean, default: false,
        desc: "Do not connect the role resource to a portal"

      def start
        configure_plutonium "config.rbac.enabled = true"
        template "config/initializers/rbac.rb"
        holders.each { |holder| wire_holder(holder) }
        wire_policy
        connect_portal unless options[:skip_portal]
        reminders
      rescue => e
        exception "#{self.class} failed:", e
      end

      private

      attr_reader :app_namespace

      Holder = Struct.new(:class_name, :association)

      def holders
        @holders ||= options[:holders].map { |spec| Holder.new(*spec.split(":", 2)) }
      end

      def membership_holder = holders.find(&:association)

      def user_holder = holders.find { |holder| holder.association.nil? }

      def wire_holder(holder)
        path = source_file_for(holder.class_name, "models")
        inject_into_file path, "  include Plutonium::Rbac::Holder\n", after: /^class .*\n/
        return unless holder.association

        inject_into_file path, "  def rbac_entity = #{holder.association}\n\n",
          before: /^\s*# add methods above\./
      end

      def wire_policy
        path = source_file_for(options[:policy], "policies")
        inject_into_file path, "  include Plutonium::Rbac::Policy\n", after: /^\s*class .*\n/
      end

      # app/<kind>/<path>.rb, or packages/<pkg>/app/<kind>/<path>.rb
      def source_file_for(class_name, kind)
        relative = "#{class_name.underscore}.rb"
        candidates = ["app/#{kind}/#{relative}"] + Dir[File.join(destination_root, "packages/*/app/#{kind}/#{relative}")]
          .map { |path| path.delete_prefix("#{destination_root}/") }
        candidates.find { |path| File.exist?(File.join(destination_root, path)) } ||
          raise("Could not find #{class_name} in app/#{kind} or packages/*/app/#{kind}")
      end

      def connect_portal
        @app_namespace = portal_option(:dest, prompt: "Select destination portal").camelize
        template "app/controllers/rbac_roles_controller.rb", controller_path
        register_resource_in_routes(routes_path, "Plutonium::Rbac::Role")
      end

      def reminders
        log :info, "rbac enabled: run `rails db:migrate`, then `rails plutonium:rbac:sync` to create system roles"
        log :info, "remove hand-written create?/read? overrides from policies that should use permissions"
      end

      def main_app? = app_namespace == "MainApp"

      def package_namespace = app_namespace.underscore

      def controller_path
        return "app/controllers/rbac_roles_controller.rb" if main_app?

        "packages/#{package_namespace}/app/controllers/#{package_namespace}/rbac_roles_controller.rb"
      end

      def routes_path
        main_app? ? "config/routes.rb" : "packages/#{package_namespace}/config/routes.rb"
      end
    end
  end
end
```
